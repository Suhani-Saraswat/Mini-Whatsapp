# 💬 Mini Whatsapp

![Node.js](https://img.shields.io/badge/Node.js-Backend-green)
![Express.js](https://img.shields.io/badge/Express.js-Framework-black)
![MongoDB](https://img.shields.io/badge/MongoDB-Database-brightgreen)
![EJS](https://img.shields.io/badge/EJS-Templates-red)

A mini messaging application inspired by WhatsApp, built to practice backend development concepts such as routing, CRUD operations, template rendering, and database interaction. This project allows users to create, view, edit, and delete chat messages while understanding how server-side logic connects with dynamic frontend rendering using EJS templates.

---

## 🚀 Features

* Create chat messages
* View all messages
* Edit existing messages
* Delete messages
* Dynamic rendering using EJS

---

## 🛠 Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose
* EJS
* CSS

---


## 🎯 Learning Purpose

This project was created to understand CRUD functionality, routing, and template rendering in backend development through a simple messaging application.
